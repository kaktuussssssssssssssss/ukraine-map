ATLAS UA — ЭТАП 1.3 / ОПТИМИЗАЦИЯ КАРТЫ
=======================================

ЧТО ИСПРАВЛЕНО
• Возвращена обычная подробная карта OpenStreetMap с названиями городов.
  Никаких платных тайлов или запросов API KEY REQUIRED.
• Удалена мировая штриховка и все связанные тяжёлые накладки.
• Области Украины показываются более заметными линиями, районы — еле заметными.
• При наведении на район линия подсвечивается, по клику можно выбрать район.
• Отдельные слои областей и районов, Canvas-отрисовка и упрощение линий.
• Районы включаются при масштабе от 5: на отдалении они не перегружают карту.
• Переход к Украине, Беларуси и западной части РФ; ограничена прокрутка далеко за их пределы.
• Панель поиска, переключение украинского/русского, включение слоёв, адаптация под телефон.

УСТАНОВКА
1. Распакуй этот ZIP на компьютере.
2. Открой репозиторий ukraine-map в GitHub.
3. Замени ТОЛЬКО три файла в корне репозитория:
   index.html
   style.css
   app.js
4. Нажми Commit changes.
5. Дождись автодеплоя в Cloudflare. Настройки сборки НЕ менять.
6. Открой сайт с Ctrl+F5 (жёсткое обновление, чтобы не остались старые CSS/JS).
7. Старый файл other-countries.geojson больше НЕ используется. Его можно удалить
   из репозитория, но для работы новой версии удалять необязательно.

ПОЯСНЕНИЯ
• Это не Google Maps API: карта на основе OpenStreetMap — она не требует ключа,
  показывает города, дороги и названия при приближении. Оригинальные Google Maps
  требуют Google Maps Platform API key и отдельной настройки оплаты/квот.
• Приложение отображает районы и области Украины, включая Крым, Донецкую и
  Луганскую области в составе Украины.
• Подложка может показывать соседние страны на краях области обзора, но
  нет мировых масок и бесконечного отдаления по всей планете.
• Два источника границ подгружаются отдельно с GitHub CDN при открытии сайта;
  при недоступности CDN есть второй URL. Рабочий интернет нужен.
• Это учебная карта. Здесь нет реальных тревог и средств отслеживания.
