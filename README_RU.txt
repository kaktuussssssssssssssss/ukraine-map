UKRAINE MAP — ЭТАП 1.1
=======================

Что нового:
- Границы районов Украины (GeoJSON, административная реформа 2020)
- Выбор района кликом по карте, выделение и приближение
- Поиск районов через левую панель
- Выбор украинского или русского языка
- Старое приближение, полноэкранный режим и карта остались

УСТАНОВКА НА GITHUB:
1. Распакуй этот ZIP.
2. Открой GitHub -> свой репозиторий ukraine-map.
3. Замени файлы index.html, style.css, app.js в КОРНЕ репозитория файлами из этой папки.
4. Файл README_RU.txt загружать необязательно.
5. После Commit changes Cloudflare сам пересоберёт сайт. Если не обновился, сделай Ctrl+F5.

ВАЖНО:
- Границы скачиваются из внешнего открытого набора данных через CDN, поэтому для них нужен интернет.
- Если источник недоступен, обычная карта продолжит работать, но границы не появятся.
- Источник границ: https://github.com/slawomirmatuszak/ukrainian_geodata
  Лицензия CC BY 4.0, атрибуция сохранена в коде и интерфейсе.
- Карта НЕ ПОКАЗЫВАЕТ реальные воздушные тревоги. Это симулятор.
- Рисование границ зависит от полноты исходного набора данных.

Этап 1.2 (в будущем): уровни учебных тревог для выбранных районов.
