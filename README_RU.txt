ATLAS UA — ЭТАП 1.2 | КАРТА С НОВЫМ ДИЗАЙНОМ
============================================

Что нового
-----------
- Полностью переработанный тёмный интерфейс, стиль ATLAS UA.
- Ночной и дневной вид карты (картографическая подложка CARTO / OSM).
- Спокойные тонкие границы районов вместо ярко-синих линий.
- Подсветка района при наведении, выделение по клику, поиск по названию.
- Все государства, КРОМЕ Украины, России и Беларуси, покрыты чёрными
  диагональными полосами, обрезанными по государственным границам.
- Отдельные переключатели границ и штриховки.
- Украинский язык основной, русский дополнительный.
- Адаптивная боковая панель для телефонов.

Установка в GitHub
-----------------
1. Распакуйте архив.
2. В своём репозитории ukraine-map замените в КОРНЕ:
   index.html
   style.css
   app.js
3. ДОБАВЬТЕ ещё один новый файл в КОРЕНЬ:
   other-countries.geojson
4. README_RU.txt загружать необязательно.
5. Нажмите Commit changes. Cloudflare опубликует обновление автоматически.

ВАЖНО: other-countries.geojson должен лежать РЯДОМ с index.html,
а не внутри отдельной папки. Без него штриховка не отобразится.

Не нужно заново подключать GitHub, создавать Cloudflare Pages/Worker,
изменять build/deploy command или настраивать переменные окружения.

Система районов загружает GeoJSON по сети. Если интернет-соединение
не позволяет получить данные, появится сообщение об ошибке.

Источник границ районов (2020):
https://github.com/slawomirmatuszak/ukrainian_geodata (CC BY 4.0)
Маска других стран: Natural Earth (public domain), упрощённые полигоны.
Базовые карты: CARTO / OpenStreetMap, см. атрибуцию внутри карты.

Это ДЕМОНСТРАЦИОННАЯ карта, НЕ официальный сервис воздушных тревог.
В версии 1.2 реальных тревог, БПЛА и военных функций НЕТ.

Тесты: синтаксис JavaScript (node --check), структура HTML,
корректность локального GeoJSON и наличие идентификаторов проверены.
Работу сетевых источников в браузере надо проверить после публикации.
