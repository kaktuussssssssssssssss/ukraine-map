ATLAS UA 1.8 — ГЕОПРИВЯЗАННЫЙ РАДАР + УРОВНИ АВТОТРЕВОГ

УСТАНОВКА
1. Распакуй ZIP.
2. В корне репозитория GitHub ukraine-map замени 8 файлов: index.html, app.js, game.js, radar.js, style.css, game.css, radar.css, leaflet-core.css.
3. Commit changes → дождись Cloudflare → Ctrl+Shift+R.
4. Cloudflare НЕ перенастраивай.

ИЗМЕНЕНИЯ
• Радар привязан к условной постоянной географической точке в центральной Украине (широта 49.17, долгота 31.31). Это не позиция настоящего радара.
• Когда ты двигаешь/приближаешь карту, радар остаётся на географической точке, а не в центре окна.
• Один оборот 4 реальные секунды при 1× (1 реальная мин = 3 игровые). На паузе сканирование заморожено.
• Отметки появляются только после прохода луча и затухают между обновлениями.
• В панели «Симуляція» есть выбор типа ИГРОВОГО сценария. В авто режиме обычный учебный БПЛА даёт ЖЁЛТУЮ тревогу; условные баллистическая, авиационная, ракетная угрозы и Бандероль — КРАСНУЮ. Никаких случайных красных тревог при учебных БПЛА.
• Ручной режим позволяет назначать любой уровень напрямую.
• Отметки радара и тревоги полностью вымышленные, никакой реальной разведывательной информации, характеристик оружия или прогнозов.
• Все прежние функции 1.7 остаются. Сохранённые тревоги не стираются.
