ATLAS UA 1.7 — РАДАР ПО ВСЕЙ КАРТЕ + ИСПРАВЛЕНИЯ

УСТАНОВКА (GitHub → ukraine-map):
1. Распакуй архив.
2. Замени в КОРНЕ репозитория: index.html, app.js, game.js, radar.js, radar.css, style.css, game.css, leaflet-core.css.
3. Commit changes. Cloudflare автоматически пересоберёт сайт.
4. Ctrl + Shift + R. Настройки Cloudflare НЕ менять.

НОВОЕ
• Радар — полупрозрачный зелёный луч вращается поверх всей видимой карты, а не в меню.
• Один оборот — 4 реальные секунды на скорости 1×; на 1× одна реальная минута = 3 игровые.
• Условные тренировочные отметки появляются только после прохода луча и затухают; позиции запоминаются на момент сканирования.
• Для тестовой метки сначала выбери район (например Миргородский), затем «Добавить учебную отметку».
• Автоматический режим больше НЕ создаёт тревоги в случайных районах.
• Чтобы запустить авто: Ctrl+кликами выдели районы → выбери Авто → «Запустить сценарий».
• Время игровых событий вымышленное, никак не связано с реальными военными маршрутами/тревогами.
• В геометрии районов для отображения заливки устранены внутренние прорези на месте воды.
• Административные границы областей остались сверху, районы выделяются при наведении.
• Состояния ранее установленных ручных тревог сохраняются после обновления.

ПРИМЕЧАНИЕ
Участок, который административно является отдельным районом, НЕ должен окрашиваться, если на него не поставлена тревога.
Для сплошной цветной территории нужно выделить все составляющие районы (Ctrl + клик).
Никаких реальных тревог, реальных радарных целей или прогнозов здесь нет.
