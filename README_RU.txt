КАРТА УКРАИНЫ — ЭТАП 1.0

ЧТО ЕСТЬ:
- Интерактивная карта OpenStreetMap на Leaflet
- Вся территория Украины, включая Крым, Донецкую и Луганскую области, в стартовом охвате карты
- Приближение, перемещение, кнопка возврата к обзору Украины, полноэкранный режим
- Переключение украинского и русского языка в интерфейсе
- Адаптация для телефона
- Пометка «Симуляция — не реальные тревоги»

ЧЕГО ПОКА НЕТ:
- Отдельного слоя границ областей и районов
- Окрашивания районов и управления тревогами
- Сценариев, радара, БПЛА и серверной части

КАК ЗАПУСТИТЬ:
1. Распакуй архив.
2. Загрузи файлы index.html, style.css, app.js в корень НОВОГО репозитория GitHub.
3. Cloudflare Pages: Connect to Git, Framework preset None, Build command пустая, Build output directory / (или .).
4. Или открой index.html локально в браузере.

Для отображения карты нужен интернет: библиотека Leaflet и тайлы OpenStreetMap загружаются с внешних серверов.
OpenStreetMap — не Google Maps, но даёт похожую интерактивную базовую карту без ключа Google API.

ВАЖНО: Это игровой/демонстрационный проект, не официальный источник информации о тревогах.
