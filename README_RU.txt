ATLAS UA — ЭТАП 1.5: СИМУЛЯЦИЯ ТРЕВОГ
======================================

ИСПРАВЛЕННАЯ СТАБИЛЬНАЯ КАРТА 1.4 + НОВЫЙ ИГРОВОЙ МОДУЛЬ 1.5.
Это учебная, полностью вымышленная симуляция, НЕ реальная карта воздушных тревог.
Не использует военную аналитику и не отправляет данные посетителей на сервер.

КАК УСТАНОВИТЬ
1. Открой репозиторий GitHub "ukraine-map".
2. Распакуй архив в отдельную папку.
3. ЗАГРУЗИ ВСЕ ШЕСТЬ ФАЙЛОВ ИЗ АРХИВА В КОРЕНЬ РЕПОЗИТОРИЯ:
   - index.html             ОБНОВИТЬ
   - app.js                 ОБНОВИТЬ
   - style.css              ИМЕЕТСЯ, МОЖНО ПЕРЕЗАЛИТЬ (та же версия)
   - leaflet-core.css       ИМЕЕТСЯ, МОЖНО ПЕРЕЗАЛИТЬ (та же версия)
   - game.js                ДОБАВИТЬ
   - game.css               ДОБАВИТЬ
   (В архиве есть также эта инструкция.)
4. В GitHub нажми "Commit changes".
5. Подожди, пока Cloudflare сам пересоберет сайт.
6. На сайте нажми Ctrl+Shift+R, чтобы убрать старый кэш.
Не нужно создавать новый проект Cloudflare, менять Build/Deploy команды или добавлять секреты.

ИГРОВОЙ ФУНКЦИОНАЛ
- Две вкладки боковой панели: СИМУЛЯЦИЯ и ГЕОГРАФИЯ.
- Быстрый поиск района прямо в игровой вкладке.
- Выбор района кликом на карте и в списках поиска.
- 3 учебных состояния для конкретного района: нет тревоги, жёлтый, красный.
- Изменяется цвет самого полигона района на карте.
- Цветные тревоги видны и на масштабе всей страны (рисуются только активные районы).
- Счётчики красных, жёлтых и суммарных активных районов.
- Игровой автоматический режим случайных событий (НЕ прогноз реальных угроз).
- Управление скоростью игрового времени: 1x, 2x, 3x, 4x, 5x.
- Кнопка паузы и продолжения времени.
- Журнал игровых событий с игровым временем.
- Локальное сохранение в браузере: уровни, режим, скорость, время, журнал.
- Сброс симуляции с подтверждением.
- Украинский / русский интерфейс, мобильная боковая панель.
- Оптимизированная отрисовка: Canvas, обновляем только изменённый район,
  без постоянной тяжёлой перерисовки и без мировых масок.
- Города/дороги по-прежнему показывает OpenStreetMap; Google Maps API не нужен.

ВАЖНО
- Режим "АВТО" сейчас ИГРОВОЙ: события случайны, не связаны с реальным движением
  воздушных объектов, не предсказывают время подлёта и не читают реальные тревоги.
- Это клиентский прототип. Разные посетители сайта играют НЕ в одной общей комнате;
  для общего онлайна позже понадобится сервер и настоящая аутентификация.
- Радар и сценарии воздушных объектов в этой версии пока НЕ добавлены.
- Данные районов и областей подгружаются из существующего открытого GeoJSON
  (как в ATLAS UA 1.4). При блокировке источника поиск и раскраска будут недоступны.
- Если в браузере заблокировано локальное хранилище, сохранение не сработает.

ПРОВЕРКА
1. Открой вкладку "Симуляція".
2. В поиске набери "Миргород", нажми на район.
3. Нажми "Жовтий" — район на карте должен стать жёлтым.
4. Нажми "Червоний" — он должен стать красным.
5. Обнови сайт — состояние должно сохраниться.
6. Нажми "Авто" и скорость "5x" — появятся игровые события.
7. Нажми "Скинути", подтверди — счётчики станут нулями.
