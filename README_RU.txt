ATLAS UA 1.4 — HOTFIX КАРТЫ
================================

Что исправлено:
- Исправлен крупный баг с разбросанными плитками и серыми пустотами на карте.
- В проект добавлен локальный leaflet-core.css: географическая карта не зависит от внешней загрузки стилей Leaflet.
- Панели масштаба больше не должны накладываться друг на друга из-за отсутствующих стилей.
- Отключена тяжёлая анимация зума, корректнее обновляется размер карты.
- Области остаются заметными; районы — почти невидимыми до наведения.
- Нет мировых масок, полос, API KEY REQUIRED и других картографических наложений.
- Геоданные районов и областей загружаются из открытого источника, поэтому для них требуется интернет.

УСТАНОВКА (важно):
1. Открой GitHub-репозиторий ukraine-map.
2. В корень репозитория, рядом с index.html, загрузи ВСЕ ЧЕТЫРЕ файла этого архива:
   index.html, style.css, app.js, leaflet-core.css
   (Первые три заменить, leaflet-core.css ДОБАВИТЬ как новый.)
3. Нажми Commit changes.
4. Дождись нового успешного деплоя Cloudflare.
5. На сайте нажми Ctrl+Shift+R или открой его в приватной вкладке.

Если осталась старая версия: проверь, что файл leaflet-core.css открывается
по адресу https://ТВОЙ-САЙТ/leaflet-core.css (без ошибки 404).

ПРИМЕЧАНИЯ:
- Используется подложка OpenStreetMap, не Google Maps API.
- Границы Украины / областей / районов относятся к демонстрационной карте, не к реальному сервису тревог.
- Проверено: node --check app.js и вычисляемые стили плиток в Chromium.
- Открытие сайта из опубликованного Cloudflare в этом окружении не проверялось.
